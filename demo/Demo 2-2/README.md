# Demo 2-2: Typography

Start with the completed Demo 2-1 website.

- `index-starter.html` and `menu-starter.html`: completed 2-1 pages, ready for students to continue.
- `css/style-starter.css`: completed 2-1 CSS. Students add their 2-2 rules at the end of this file.
- `index.html` and `menu.html`: completed 2-2 examples.
- `css/style.css`: completed 2-2 CSS.
- `images/`: shared photographs and favicon.

## Four tasks

1. Style `body`: Arial, Helvetica, sans-serif; 16px; color #3d3028; line-height 1.6.
2. Style `h1, h2, h3`: Georgia, "Times New Roman", serif; color #b4430b; line-height 1.2. Set h1 to 40px, h2 to 24px, and h3 to 20px.
3. Set `.featured-dish > p` to uppercase and `.dish-heading p` to bold. The first selects category paragraphs directly inside featured dishes; the second selects menu prices inside dish-heading groups.
4. Set `.menu-item` to height auto and min-height 160px so cards can grow with their text. Check both starter pages at 200% browser zoom, then reset zoom.

Keep the 2-1 content and layout. No HTML edits are needed. Keep the whole folder together.
